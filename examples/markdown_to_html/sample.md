# Markdown to HTML

Drop Markdown files on Markdown to HTML, or open them with it, and it writes each one's HTML beside it, read as GitHub-Flavored Markdown, with its fenced code, tables, ~~strikethrough~~, and task lists:

- [x] A file dropped on the app
- [x] A file opened with the app
- [ ] A window to look at

| Program | Started by |
| ------- | ---------- |
| the droplet | a drop, or Open With |
| `md2html` | a terminal |

```ruby
puts "Written beside the file"
```
