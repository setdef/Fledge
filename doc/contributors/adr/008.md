# ADR 008: An App Shows the Identity Its fledge.yml Gives It, With One Name Everywhere

## Context and Problem Statement

Every operating system shows an app's name and icon where a person meets it. Windows shows them in Explorer, the taskbar, Alt-Tab, the Start menu, and Task Manager, which names a process by its program's FileDescription. macOS shows them in the Dock, Cmd-Tab, the menu bar, and Finder, all read from a bundle's `Info.plist`. Linux desktops read a desktop entry and an icon theme. Two systems also know an app by an identifier, whose origin is ADR 064's.

The maintainer's decision 18 (`decisions.md`, 2026-10-26) puts all of this in the developer's hands: "Would this affect what shows up in the taskbar? task manager? start menu? desktop icons? app window top-left corner and/or title bar? If so, app devs need to be able to control it." The launcher is one program for every app, built once per runtime in Fledge's CI (ADR 001), so each app's identity goes into its copy when `fledge build` runs. How should the developer name the app?

## Decision Drivers

- Decision 18: the developer controls what every system shows.
- Every place a person sees the app should agree on its name.
- A project with no `fledge.yml` still builds the console app it built before.
- Prior art: Tauri's `productName`.

## Considered Options

1. One `name` for every place.
2. A display name beside a file name, so the program's file and the shown name may differ.

## Decision Outcome

Chosen: option 1, because one name is what Tauri's `productName` is and keeps the program, its folder, its archive, its bundle, its version information, and its desktop entry from disagreeing. No reason was recorded against option 2 beyond that.

`fledge.yml` (ADR 044) holds `name`, `kind`, `identifier`, `version`, `icon`, `publisher`, `copyright`, `description`, `long_description`, and `homepage`. `name`, `kind`, `version`, and `publisher` have defaults, and the rest may be left out, so a project with no `fledge.yml` still builds. The `identifier` is ADR 064's. Fledge makes no legal statement for a developer, so `copyright` has no default.

Confidence: high. Delivery reads every identity back with each system's own tools on fresh computers.

### Consequences

- Good, because every Windows app, console ones too, names itself and shows its version in Task Manager and Explorer, every windowed macOS app shows its name, icon, and identifier in the Dock and Finder, and every windowed Linux app carries what a desktop needs to list it.
- Bad, because a name may hold spaces ("Hello Window"), so it is a poor command name; a `.deb` puts no program on a `PATH` for this reason (ADR 021).
- Bad, because Windows' version numbers hold 16 bits a part, so a version with a part above 65535 fails a Windows build.
- Neutral, because Fledge keeps its own mapping of these keys onto each system's fields (`doc/contributors/design/desktop-apps.md`, "Identity on each system"), which a maintainer updates when a system adds a field.

### Confirmation

`test/identity_test.rb`, `test/config_test.rb`, `test/mac_bundle_test.rb`, `test/windows_resources_test.rb`, and `test/desktop_entry_test.rb` hold the defaults, the refusals, and each system's fields. Delivery runs `examples/windowed_app`, whose name has a space, on fresh runners: `.github/scripts/deliver-windowed.sh` reads its bundle with `plutil` and `codesign --verify --strict --deep` and its desktop entry with `desktop-file-validate`, and `.github/scripts/deliver-windowed.ps1` reads its version information and its AppUserModelID.

## More Information

- The keys' defaults and rules, and how each system shows them: `doc/contributors/design/desktop-apps.md`, "Identity on each system". The developer's view: `doc/desktop_apps.md`, "Name and describe your app" and "Make a windowed app".
- The identifier: ADR 064. The icon is the developer's own files (ADR 048); the kinds of app are ADR 037; a project of several programs gives each program its own name and identifier (ADR 024).
- `publisher` defaults to the gemspec's authors, the Ruby project's own statement of who made it. Tauri defaults its publisher to a part of the identifier, which in Ruby says less.
