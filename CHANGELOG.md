### Added

- `fledge --help` (`-h`) and `fledge --version` (`-V`).
- `fledge build [-t PLATFORM]... [-o DIR] [PATH]`: copies the app in PATH into a runtime for each target and writes `DIR/NAME-PLATFORM/` and `DIR/NAME-PLATFORM.tar.gz`, printing each archive's path. Targets: `arm64-darwin`, `x86_64-linux`, `aarch64-linux`.
- Runtimes download from the GitHub Release of Fledge's version into `~/.cache/fledge/runtimes` (or `$XDG_CACHE_HOME/fledge/runtimes`), checked against the release's `SHA256SUMS`; `FLEDGE_RUNTIME_DIR` names a folder of runtimes to use instead.
- Runtimes carry Ruby 4.0.9 from rv-ruby release `20261023` with its standard library and default gems (no bundled gems), a launcher that ignores the user's Ruby environment, libxcrypt 4.5.2 as a shared library on Linux, and license notices in `notices/`. Linux apps need glibc 2.39 or newer.
